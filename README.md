# 💡 Bulb Toggle Switch | HTML & CSS

A clean and smooth **bulb toggle switch** built using **pure HTML and CSS**.  
This toggle features a **lever-style switch with a curved handle** — perfect for **dark mode toggles**, **UI components**, and **modern web design**.

---

## ✨ Features
- ✅ 100% HTML & CSS — No JavaScript
- 💡 Smooth lever flip animation
- 🎨 Rounded handle design with realistic glow effect
- 🖥️ Fully responsive and minimal

---
